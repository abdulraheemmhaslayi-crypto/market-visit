4. Core Technical Architecture & Security Model

Full Enterprise Technology Stack

The platform is engineered on a modern enterprise stack designed for high throughput, sub-second query response times, and resilience in low-bandwidth field environments:

  • Frontend Layer: Next.js 16 (App Router), React 19, TypeScript, Vanilla CSS design tokens with executive theme engine.
  • Offline & PWA: Progressive Web App with custom Service Worker (`sw.ts`), smart route bypass for dynamic APIs, client image down-sampling, and IndexedDB sync engine.
  • Database & Dual-Engine ORM: Dual-Engine Architecture supporting Microsoft Azure SQL Server and MySQL with connection pooling and native T-SQL MERGE statements.
  • Master Data Pipeline: Disk-persisted runtime Excel ingestion (`data/` directory) with automated in-memory cache eviction and live client distribution.
  • Cloud Hosting & CI/CD: Microsoft Azure App Service with automated GitHub Actions CI/CD pipeline and Next.js standalone container deployment.
  • Security & Access Control: Role-Based Access Control (Admin, Sub-Admin, Supervisor) with tamper-resistant camera-only proof enforcement.
