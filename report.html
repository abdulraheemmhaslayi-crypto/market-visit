3. Critical Architectural Bug Fixes & Problem Remediations

Issue Identified Technical Root Cause & Remediation Implemented Operational Impact Resolved
Directive Action Leak Flagged directives in Audit Photo Gallery were displaying across all photos and supervisors. Remediated by strictly isolating directives to compound key (`photoId + outletCode + supervisor`). Directives now appear exclusively on the exact photo, outlet, and supervisor intended. Resolved
Oct 14, 2026
Saifullah vs Saif Ambiguity Two supervisors with similar names were colliding in reports. Remediated by strictly separating Supervisor Saifullah (Manager: Adnan) from Supervisor Saif (Manager: Ashfaq) in database queries and slicers. Completely eradicated supervisor misattribution and reporting cross-talk. Resolved
Sep 30, 2026
Channel Nomenclature Legacy records referenced "General Trade (GT)". Remediated across all APIs, models, and UI components to official Dandy Traditional Trade (TT) vs Modern Trade (MT). Standardized operational nomenclature across all commercial reports. Resolved
Sep 30, 2026
Power SKU Denominator Power SKU compliance was defaulting to 41 SKUs or exceeding 100%. Remediated by strictly enforcing business rule: MT = 24 Power SKUs, TT = 27 Power SKUs, with Y-axis strictly capped at 100%. Audited scores represent true store compliance without mathematical distortion. Resolved
Oct 11, 2026
Master Data Import Crash Server Action threw foreign key constraint errors when re-importing customer master files. Remediated by implementing ordered upsert transactions that preserve active audit linkages. Weekly customer master updates run seamlessly without wiping audit history. Resolved
Oct 13, 2026

Remediated by switching to standalone container output (`output: 'standalone'`) with runtime env injection. Permanent deployment reliability on Microsoft Azure cloud infrastructure. Resolved

4. Core Technical Architecture & Security Model

Full Enterprise Technology Stack

The platform is engineered on a modern enterprise stack designed for high throughput, sub-second query response times, and resilience in low-bandwidth field environments:

  • Frontend Layer: Next.js 16 (App Router), React 19, TypeScript, Vanilla CSS design tokens with executive theme engine.
  • Offline & PWA: Progressive Web App with custom service worker caching, client image compression, and background sync.
  • Database & ORM: Dual-Engine Architecture supporting Microsoft Azure SQL Server and MySQL with connection pooling.
  • Cloud Hosting: Microsoft Azure App Service with automated GitHub Actions CI/CD pipeline and Next.js standalone builds.
  • Security & Access Control: Role-Based Access Control (Admin, Sub-Admin, Supervisor) with tamper-resistant camera-only proof enforcement.
