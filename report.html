4. Core Technical Architecture & Security Model

Enterprise Architecture Overview
The platform is engineered on a resilient multi-tier enterprise stack designed for high throughput, sub-second query response times, and resilience in low-bandwidth field environments:
Layer / Subsystem Technical Implementation & Enterprise Governance
Frontend & Client Layer Next.js 16 (App Router), React 19, TypeScript, Vanilla CSS design tokens with executive dark/light themes, Lucide icon system, and responsive viewport fitting without horizontal scroll.
Offline & Edge PWA Engine Custom Service Worker (sw.ts) using Serwist/Workbox, smart route bypass for dynamic Next.js /api/* mutations, client-side JPEG down-sampling (image-compressor.ts), and IndexedDB background sync queue.
High-Concurrency MSSQL Engine Azure SQL Server with dedicated connection pooling, isolated sql.Request transaction scopes, derived table batching, and WITH (HOLDLOCK) table hints eliminating Deadlock 1205.
Dual-Engine Database Failover Dual-Engine Architecture natively supporting Microsoft Azure SQL Server (production) with automated failover detection to Railway/MySQL, complete with engine-specific T-SQL vs standard SQL syntax handlers.
Master Data Pipeline & Cache Disk-persisted runtime Excel ingestion in data/ directory, dynamic schema validation, automated in-memory cache eviction (dashboard-cache.ts), and real-time live synchronization across field devices.
Cloud Hosting & DevOps CI/CD Microsoft Azure App Service Linux container hosting, Next.js standalone container deployment, custom domain binding to dandyapp.tech, and automated GitHub Actions CI/CD pipeline.
Identity & Data Security Model Role-Based Access Control (Admin, Sub-Admin, Supervisor), bcrypt password hashing, NextAuth v5 session hardening with proxy host sanitization, and tamper-resistant camera-only proof enforcement.
